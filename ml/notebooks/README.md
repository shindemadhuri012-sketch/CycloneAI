# ML Research Notebooks (`ml/notebooks/`)

## Purpose
Contains exploratory Jupyter notebooks for dataset inspection, EDA, prototyping transformations, and visual validation.

## Guidelines
- Notebooks are strictly for research and exploration.
- Reusable logic, models, and data loaders must be refactored into the structured python packages in `ml/preprocessing`, `ml/datasets`, or `ml/models`.
- Do not commit large inline notebook outputs or raw satellite arrays.
